## 📌 Proyectos destacados

### [Botica CRM](https://github.com/ArnieAF/botica-crm)
CRM en producción para una botica magistral. Registra pedidos y calcula la ganancia real de cada venta, mide qué red social trae más clientes y **publica sola carruseles en Instagram y Facebook** con la Meta Graph API.
`Next.js 16` `TypeScript` `Supabase` `PostgreSQL` `Row Level Security` `Vercel Cron`

### [API Biblioteca](https://github.com/ArnieAF/ApiRestBiblioteca)
API REST para gestionar autores, libros, usuarios y reservas, con autenticación JWT, roles `USER`/`ADMIN`, validaciones y documentación en Swagger.
`Java 17` `Spring Boot 3` `Spring Security` `JWT` `SQL Server` `MapStruct`
